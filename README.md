# Portfolio Website - Django

A personal portfolio website built with Django, HTML, CSS, and JavaScript to showcase my skills, projects, education, and development journey.

## About the Project

This project is the initial version of my personal developer portfolio.

I started building this portfolio to create a professional online presence and apply my Django, HTML, and CSS knowledge to a real-world project.

The current version focuses on the core structure, responsive layout, navigation, skills, projects, and contact sections.

This is not the final version. I intentionally started with the fundamental structure and will continue improving the design, functionality, and overall user experience in future iterations.

## Features

- Responsive portfolio layout
- Hero section
- About section
- Skills section
- Projects section
- Contact section
- Email, GitHub and LinkedIn links
- Download CV option
- Django template structure
- Custom CSS styling
